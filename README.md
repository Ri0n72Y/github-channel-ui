# LabourChain

LabourChain 是面向黑客松团队和开源社区的 GitHub 项目协作平台，围绕公开仓库整合项目发现、Issue 看板、频道讨论和基础劳动记录。

本仓库用于 LabourChain MVP 的开发与验证。
